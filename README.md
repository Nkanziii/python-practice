# Python practice

A collection of daily Python practice exercises and scripts built while learning Python from scratch.

## What's here

**Exercises** - small functions practicing core concepts: 

- String manipulation (reverse, palindrome, caesar cipher)
- List operations (flatten, duplicates, sorting)
- Dictionary problems (merge, invert, frequency counting)
- Algorithms (two sum, second larges, FizzBuzz)

**Scripts** - full CLI programs:

- Word counter, temperature converter, guessing game
- Shopping cart, contact book, library manager
- bank accounts, to do list, expense tracker
- Grade analyzer, password validator

## Built with:

- Python 3
- No frameworks - pure Python logic

## Purpose:

Daily practice sessions building Python independence from scratch. working towards a generative AI engineering role.
